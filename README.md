# 🗳️ Voting Poll App

## Description

This is a simple and interactive polling application where users can create polls, vote on options, and view real-time results.

---

## Features

* Create polls with multiple options
* Vote on polls
* View results in percentage format

---

## 🛠️ Tech Stack

* Frontend: React.js,javascript
* Backend: Node.js, Express.js
* API: REST API
---

## Usage
* Create a poll
* Share with users
* Vote and see results instantly in animation effect.
* user can delete the poll
